# Negative Keywords: Relaunch List

Built 2026-09-29 from PPC-AUDIT.md plus the old campaign's search terms report (Aug 7 – Sep 27). Paste the block below into a **shared negative keyword list** (steps at the bottom) and apply it to `Search – Nashville Leads (Relaunch)`.

Everything is **phrase match** (in quotes). A phrase negative blocks any search containing those words in that order, so `"reviews"` blocks "don kennedy roofing reviews" and "best roofers reviews". Competitor names are phrase match too, so they also catch "<name> reviews" and "<name> near me".

**Never add** anything containing `stellar`, `free roof inspection`, `roof repair`, `roof replacement`, or `roofer`/`roofers`: those are our own searches.

## Changed from the PPC-AUDIT.md list

- `"free roof"` became `"free roof replacement"`, `"free roof program"`, and `"free roofs"`. The original would have blocked **"free roof inspection"**, which is our own offer.
- `"pitch"` became `"roof pitch"`, so it doesn't block searches like "steep pitch roof repair".
- Competitors are phrase match instead of exact. Exact match only blocks the name typed alone, but most competitor searches in the report were "<name> reviews" or "<name> <city>".

## How to add it in Google Ads

1. **Tools** (wrench icon) → **Shared library** → **Exclusion lists** (older menus call it "Negative keyword lists").
2. **+** → name it `Relaunch negatives` → paste the whole block above → **Save**.
3. Open the list → **Apply to campaigns** → pick `Search – Nashville Leads (Relaunch)` → **Apply**.

## Where new negatives come from

Google Ads → **Insights and reports** → **Search terms** (or open the campaign → **Keywords** → **Search terms**). It lists the exact searches that triggered your ads. Every 2–3 days for the first 2 weeks, **export it and send it to Claude**. Claude flags junk searches to add to this list. You can also tick a search term's box → **Add as negative keyword** → choose the `Relaunch negatives` list.
